# (not)AI Time Tracker

Локальный трекер времени для Android с независимым Kotlin-ядром. Он хранит одну активную сессию, её рабочие отрезки, классификацию и заметки. Историю можно исправлять, просматривать по дням и переносить через файлы. Сервер, аккаунт и сетевые API для работы не нужны.

Проект находится на этапе разработки. Android-приложение **0.10.0** получило основной интерфейс на Jetpack Compose: немедленный старт, выбор занятия после старта, история по дням с исправлением и ручными записями, неизвестное время, Focus, обзор и данные, светлая и тёмная темы. Прежняя техническая оболочка осталась отдельным экраном для функций без продуктового оформления. Сборка, JVM/Room-сценарии и Robolectric-отрисовка экранов имеют сохранённые результаты, но запуск на физическом Android-устройстве, поведение разрешений и доступность интерфейса пока не проверены. Подробности: [интерфейс](docs/UI.md), [состояние проекта](docs/ACCEPTANCE_GAPS.md) и [проверки](docs/VERIFICATION.md).

## Возможности ядра

- Start, Pause, Resume, Stop и Switch на одной временной шкале; восстановление неопределённого хвоста после потери временной опоры.
- Личные карточки, избранные варианты, повтор, заметки и необязательная классификация через дерево типов и независимые признаки.
- Ручные интервалы, исправление истории с предварительным просмотром и одношаговая отмена в пределах процесса.
- Отчёты, календарная проекция истории, группы точных сохранённых вариантов и CSV. Зона отчёта задаётся явно; переходы летнего времени учитываются.
- Поиск и предложения из записанной истории с постраничным API; цели по времени или числу сессий; интервалы работы и перерыва Focus.
- Полная JSON-копия с предварительным просмотром, проверенной откатной копией и атомарным восстановлением. CSV-импорт добавляет историю после явного сопоставления колонок и классификации.

Эти возможности доступны через API ядра. Основной интерфейс покрывает таймер, выбор и поиск занятий, избранное и повтор, исправление и ручные записи, переключение задним числом, неизвестное время, Focus, обзор с целями, копию, восстановление и CSV-выгрузку, поверхности и тему. Техническая оболочка (`TechnicalActivity`, «Данные → Техническая оболочка») остаётся для CSV mapping, измерений, календарных вхождений, восстановления недоступной базы и правки целей.

## Принципы

Учёт времени отделён от интерфейса. Все изменения проходят через `Tracker` и транзакцию `StateStore`; интерфейс не рассчитывает длительности и не записывает строки базы самостоятельно. Для обычного таймера не нужен постоянный сервис, секундные тики не пишут в базу.

Неизвестное время остаётся неопределённым до явного решения пользователя. Переименование или перемещение типа не переклассифицирует прошлые записи. Количества сохраняются точными десятичными значениями; величина всей сессии не распределяется по дням автоматически. Пересекающиеся классификации не добавляют время к общему итогу.

Системный Android backup и device transfer отключены в manifest/rules. Это настройка приложения, а не результат проверки всех OEM-механизмов. Ручной restore полностью заменяет данные; merge истории и синхронизация отсутствуют. Полные JSON-копии и восстановление читаются и пишутся потоково без общего лимита 10 MiB. CSV ограничен 10 MiB, 50 000 строк и 128 колонками. Полный граф данных всё ещё хранится в памяти; свободное место и память устройства ограничивают практический объём.

## Сборка

Нужны JDK 17 или 21, Android SDK Platform 35 и Build Tools 35.0.0. Укажите `ANDROID_HOME` либо `sdk.dir` в локальном `local.properties`. Gradle Wrapper 8.13 включён; SHA‑256 дистрибутива закреплён. Kotlin 2.1.20, AGP 8.11.1 и Room 2.7.2 заданы в Gradle-файлах. Минимальная версия Android — 8.0 / API 26, target SDK — 35.

```sh
./gradlew :core:test :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Debug APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`. Для отдельной проверки на подключённом устройстве:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n dev.notai.tracker/dev.notai.tracker.android.MainActivity
```

Эти команды не означают, что проверка устройства уже выполнена. Для установки поверх ранее подписанного APK нужен тот же signing key; новая локальная debug-подпись отличается от APK исходной поставки. Исходный ключ не включён в репозиторий. `--offline` допустим только при заранее заполненном кэше зависимостей. SDK, кэши, credentials и `local.properties` в Git не добавляются.

Новая установка сразу получает полный готовый каталог: 1918 типов и 337 осей, версия 0.9.1.3. APK содержит снимок словаря, manifest и проверяемые правила совместимости описательных обновлений. Исходные исследования и их обработчики отделены от приложения и сохранены во внешних архивах и истории Git. Обновление существующей установки требует preview и подтверждения; личные имена, архивность и прошлые классификации сохраняются.

Зона новой установки берётся с устройства один раз. Дальнейшие изменения зоны отчётов подтверждаются явно; зоны целей независимы. Технический экран (`TechnicalActivity`) предоставляет выбор карточки и избранного по ID, полный каталог с поиском и страницами, Focus с необязательным фоновым уведомлением, выбор календарного вхождения, явный CSV mapping, количества целого target, устойчивый SAF-экспорт и recovery без открытия неисправной базы.

Файл лицензии пока отсутствует; условия распространения ещё не выбраны.
