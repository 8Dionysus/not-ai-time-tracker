# (not)AI Time Tracker — локальное ядро

Нативный Android-проект без сервера, ИИ/API, аккаунтов и постоянного сервиса отсчёта. Kotlin-ядро вызывает Room через одну транзакционную границу. `app` — только техническая оболочка для проверки; продуктовый UI остаётся отдельной работой Диониса и Opus.

## Сборка

Нужны JDK 17–21, Android SDK Platform 35, Build Tools 35.0.0. Gradle Wrapper 8.13 включён и проверяет SHA-256 дистрибутива. Версии Kotlin 2.1.20, AGP 8.11.1, Room 2.7.2 закреплены.

```sh
# ANDROID_HOME указывает на установленный SDK; либо sdk.dir в local.properties.
./gradlew :core:test
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n dev.notai.tracker/dev.notai.tracker.android.MainActivity
```

В облачной среде рабочие кэши должны быть доступны на запись; команды и фактические результаты данного прохода — [docs/VERIFICATION.md](docs/VERIFICATION.md). Не помещать credentials, прокси-настройки конкретной среды и `local.properties` в Git.

## Структура и граница UI

- `core/Model.kt`: схема предметных данных, проверки инвариантов; временный seed загружается из JSON-ресурса. Своя карточка требует только имени.
- `core/Vocabulary.kt`: единое дерево типов, снимки пути, оси/значения, точные Decimal и единицы.
- `core/Tracker.kt`: команды, ревизии, состояния, монотонное время, одношаговая отмена.
- `core/Reports.kt`: история, дневные окна, сравнения, фильтры, CSV из тех же строк отчёта.
- `core/Backup.kt`: версия JSON 7 с чтением v1–v6, просмотр восстановления, проверенная откатная копия, полная замена.
- `app/.../TrackerDatabase.kt`: Room schema 3 с миграциями 1→2→3, атомарная запись и чтение обратно; внешний ключ сессии, уникальный слот открытого сегмента.
- `app/.../AndroidRuntime.kt`: единый runtime, Android elapsedRealtime/BOOT_COUNT, приватные откатные файлы.
- `app/.../MainActivity.kt`: удаляемая техническая оболочка с кнопками и Storage Access Framework.

Подробный контракт: [docs/UI_CONTRACT.md](docs/UI_CONTRACT.md). JSON-примеры: [samples](samples).

## Политики первого среза

Зона отчётов хранится явно, исходное значение — `UTC`. Изменение зоны меняет представление, не timestamps. Дни строятся через `ZoneId`/`LocalDate`, включая DST. Неопределённые отрезки выводятся отдельно и не получают выдуманного дневного распределения.

Автоматические cloud backup и device transfer отключены в manifest и extraction rules. Проверка этого манифеста не означает проверки всех OEM-механизмов на физических устройствах. Ручной JSON — отдельная, явная операция.

Сетевых и DND-разрешений нет. Уведомления и overlay запрашивают разрешения только при включении пользователем; их отказ не блокирует запуск и историю внутри приложения. Overlay использует отдельный FGS только для видимых плавающих кнопок, с обязательным системным индикатором. Обычный таймер сервиса не требует. Блокировочный экран может использовать только `safeLabel`; названия и заметки не входят в эту подпись.

Room сохраняет только изменённые строки через UPSERT и проверяет их чтением обратно в одной транзакции, без ежесекундных записей. Неизменившиеся словари не переписываются; поколение хранилища проверяет актуальность кеша. Холодное чтение и смена поколения по-прежнему загружают весь граф, а полная валидация на недоверенных границах и отчёты работают в памяти. Горячие команды переиспользуют защищённый граф и компактный индекс; копирование списков истории пока остаётся линейным. Производительность на многолетних миллионах записей не проверена. JSON ограничен 10 MiB при импорте. Room-таблицы содержат версии сериализованных записей плюс структурные ключи; сложные SQL-отчёты намеренно не вводились.

## Дальнейший согласованный объём

Продуктовый UI и проверка Android-поверхностей на устройстве, сигналы/системные интеграции Focus, календарь, выделенный текст, контекстные подсказки значений и UI автодополнения, группировка похожих записей, дополнительные игровые элементы. Они не являются платными ограничениями ядра. UI не должен заново реализовывать бизнес-логику или закрывать сегменты самостоятельно. Синхронизация и merge отсутствуют.

Расширение каталога и его незакрытый вход: [docs/CATALOG_IMPACT.md](docs/CATALOG_IMPACT.md). Пять технических узлов не являются полным перечнем занятий человека.

Адаптер полного полученного корпуса 0.5, API, фактическое покрытие и остаток: [docs/RESEARCH_ADAPTER.md](docs/RESEARCH_ADAPTER.md).

Текущий разбор оставшихся осей, составных значений, количеств и пяти проверенных оригиналов: [RESEARCH_FOLLOWUP.md](docs/RESEARCH_FOLLOWUP.md). Подготовлены 82 необязательные оси; 17 схем выбираются явно через configureAxis. Реальные 357 междоменных связей проверены как доказательства, без изменения дерева и времени.

Исправление и расширение количественных представлений после приёмки v6: [QUANTITY_REVIEW.md](docs/QUANTITY_REVIEW.md). Общая запасная формулировка удалена; 71 запись разобрана явно, категории не преобразуются в числа.

Обычные функции — бесплатный продуктовый объём. Подписка на будущий ИИ не входит в ядро. Лицензия и публикация репозитория этим проходом не выбирались.
