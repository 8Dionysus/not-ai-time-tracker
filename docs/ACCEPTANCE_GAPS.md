# Остаток приёмки

Текущее дополнение: полный baseline + исправленные ISCO v2 и спорт 0.7 интегрированы в FullResearchCatalog. Покрытие, контракт и точный остаток — [FULL_CATALOG_07.md](FULL_CATALOG_07.md); ниже сохранена история предшествующего среза.

## Что закрыто после первичной сверки

APK/Room/lint выполнены; схема Room сгенерирована. Все STALE, включая Undo, несут актуальный Snapshot. Change содержит согласованные данные/asOf, затронутые записи и расчёт report/day; изменение измерений отмечает сессию. «Считать частью» ссылается на сохранённый реестр ActivityType с устойчивыми ID и валидацией ссылок; переименование, архивирование и JSON-восстановление проверены. Добавлены атомарная правка завершённой сессии/заметки, удаление измерения и снятие избранного. Каталог содержит поисковые имена. Добавлены сравнение равных календарных периодов через DST и безопасные quantity-суммы по версиям/единицам/scope; проверены архивные Repeat/Favorite, диапазоны целых и фактический rollback SQLite после промежуточных записей. Свидетельства — VERIFICATION.md.

## Не выполнено из приёмки первого среза

1. Полный путь на устройстве/эмуляторе: Activity, SAF, реальный kill/restart, сон и reboot, доступность/озвучивание. Room/Robolectric не заменяет эту проверку. adb devices -l успешно выполнен с отдельным HOME дочернего процесса и вернул пустой список; нет screenshots/logcat. До неё нельзя назвать Android-приложение полностью принятым.
2. Действие системного backup/device transfer на конкретном OEM: исходный и собранный manifest проверены, реальное поведение устройства — нет.
3. Private GitHub repo/push: отсутствует разрешённая callable операция создания, CLI-токен недействителен. Локальный репозиторий и bundle подготовлены, credentials не менялись.
Первая версия архива доставлена Дионису как вложение Library и независимо проверена родителем (CRC ZIP, SHA-256 APK, XML и lint). Обновления сохраняются в тот же Library item; новая версия и контрольные суммы сообщаются отдельно.

## Явные границы текущего API

- correctSession сохраняет все существующие сегменты завершённой сессии и заметку атомарно; не добавляет/удаляет сегменты формы. switchedEarlier работает внутри текущего непрерывного сегмента; произвольного переноса границы между двумя давно завершёнными сессиями отдельной командой нет.
- Единое рекурсивное дерево ActivityType, исторические пути, оси/значения и Decimal реализованы в v2 с миграциями. Полное наполнение каталога не завершено: входной Library JSON не материализован из-за ошибки передачи, расширенное дерево готовится отдельно. Пять прежних узлов — только технический ресурс для совместимости, не итоговый охват. Подробности и ожидаемый hash — CATALOG_IMPACT.md.
- Reports.compare — для равного физического времени; compareCalendarDays — для равного числа местных календарных дней, включая DST. Неполный период помечается; автоматического обрезания предыдущего окна нет. quantityTotals относятся к полным затронутым сессиям/сегментам, а не к количествам внутри дня; нельзя складывать эти величины из разных дневных отчётов.
- Undo одношаговая, в памяти процесса. JSON — только полная замена без merge, импорт до 10 MiB. Автоматическая очистка rollback-копий отсутствует.
- Room пишет полный граф только по пользовательским командам; масштаб/скорость на многолетней истории не измерены. Оптимизация не заявлена.
- Техническая оболочка использует точное имя карточки и ISO-8601, не предоставляет весь API удобными формами; продуктовый UI ещё предстоит.

## Конкретный остаток технической оболочки после v9

Статический обзор MainActivity: секундный цикл полного чтения базы и пересчёта отменяется только в onDestroy. Возможна лишняя работа в фоне между onStop и onDestroy; измерений расхода/скорости нет. На этапе оболочки привязать обновление к видимому lifecycle и проверить, нужен ли полный read/report каждую секунду. В текущем исправлении UI, bootstrap и устройство не менялись.
