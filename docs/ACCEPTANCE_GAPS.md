# Остаток приёмки

## Что закрыто после первичной сверки

APK/Room/lint выполнены; схема Room сгенерирована. Все STALE, включая Undo, несут актуальный Snapshot. Change содержит согласованные данные/asOf, затронутые записи и расчёт report/day; изменение измерений отмечает сессию. «Считать частью» ссылается на сохранённый реестр ActivityType с устойчивыми ID и валидацией ссылок; переименование, архивирование и JSON-восстановление проверены. Добавлены атомарная правка завершённой сессии/заметки, удаление измерения и снятие избранного. Каталог содержит поисковые имена. Свидетельства — VERIFICATION.md.

## Не выполнено из приёмки первого среза

1. Полный путь на устройстве/эмуляторе: Activity, SAF, реальный kill/restart, сон и reboot, доступность/озвучивание. Room/Robolectric не заменяет эту проверку. Нет подтверждённого adb-target; нет screenshots/logcat. До неё нельзя назвать Android-приложение полностью принятым.
2. Действие системного backup/device transfer на конкретном OEM: исходный и собранный manifest проверены, реальное поведение устройства — нет.
3. Private GitHub repo/push: отсутствует разрешённая callable операция создания, CLI-токен недействителен. Локальный репозиторий и bundle подготовлены, credentials не менялись.
4. Доставка пользователю: локальный путь не доказывает доступность байтов; фактический результат загрузки архива приводится отдельно в сообщении приёмки.

## Явные границы текущего API

- correctSession сохраняет все существующие сегменты завершённой сессии и заметку атомарно; не добавляет/удаляет сегменты формы. switchedEarlier работает внутри текущего непрерывного сегмента; произвольного переноса границы между двумя давно завершёнными сессиями отдельной командой нет.
- ActivityType — плоский реестр типов/широких областей. Многоуровневой иерархии и автоматического наследования нет; связь задаётся явно.
- Измерения: целые неотрицательные значения, fieldId/meaningVersion/unit/scope; отсутствующее значение и ноль различаются. Редактор определений полей, дробные величины и преобразование единиц не реализованы.
- Reports.compare требует равной физической длительности окон. Календарные периоды с разным числом часов на DST сравнивать этой функцией нельзя. Неполный период помечается; автоматического обрезания предыдущего окна нет.
- Undo одношаговая, в памяти процесса. JSON — только полная замена без merge, импорт до 10 MiB. Автоматическая очистка rollback-копий отсутствует.
- Room пишет полный граф только по пользовательским командам; масштаб/скорость на многолетней истории не измерены. Оптимизация не заявлена.
- Техническая оболочка использует точное имя карточки и ISO-8601, не предоставляет весь API удобными формами; продуктовый UI ещё предстоит.

## Отложено по согласованному продуктовому объёму

Продуктовый UI и интеграция с ним; виджет; overlay; уведомления/быстрые действия; Focus/перерывы/музыка/DND; календарь, копирование и старт события; выделенный текст; автодополнение, частые занятия и предложения; группировка похожих записей; цели/вехи/геймификация. Они остаются бесплатными требованиями будущих этапов. Пользовательская граница дня — кандидат настройки. Сервер, модельные API, KMP и синхродвижок не являются предварительными условиями и не добавлены.
