# Готовый каталог

Приложение получает подготовленный `VocabularyData`, а не исходные исследования. В `catalog/` находятся три файла: `manifest.json`, `runtime-catalog.json`, `compatibility.json`. Manifest закрепляет версию, размер и SHA-256 каждого payload. `ReadyCatalog.read` проверяет их, ссылки и структуру, затем возвращает неизменяемый словарь. Неверный пакет не устанавливается.

Текущий пакет 0.9.1.3 содержит все 1918 типов и 337 осей. 178 описаний и три имени уточнены в 179 записях; остальные значения, ID, родительские связи, selectable и meaningVersion сохранены. Частный файл редакторских поправок не включён в APK или дерево репозитория. Предыдущий готовый словарь присутствует только в сжатом тестовом fixture для проверки миграции.

## Новая и существующая установка

Новая база создаётся с полным готовым словарём и локальной зоной устройства. Пять технических bootstrap-типов сохраняются для совместимости старых копий и тестов; они не являются начальным пользовательским каталогом новой установки.

Существующая база не перезаписывается при запуске. `CatalogImports.prepare()` показывает added/updated/unchanged/conflicts; отмена ничего не пишет. `apply(preview)` требует исходный token, проверяет пакет и меняет словарь атомарно. История, карточки, избранное, aliases, архивность и личные названия сохраняются. Повтор не создаёт дубликатов. Пустая nonselectable группа скрыта из обычного выбора, её ID сохранён для совместимости.

## Совместимость

Технические origin/hash-поля не определяют семантическую идентичность. Стабильное значение с новым provenance остаётся unchanged; локальное представление не заменяется.

Изменённое описание принимается только для явно перечисленного правила: текущий смысл совпадает с `fromMeaningSha256`, новый — с `toMeaningSha256`, прочие смысловые поля совпадают. Уже установленный новый смысл также принимается. Штатное имя обновляется только при совпадении хеша старого стандартного имени; личное имя сохраняется. Произвольные смысловые изменения конфликтуют. Обычный публичный `addCatalog` имеет строгую политику и не получает редакторских исключений.

Ядро не содержит известных пар исследовательских SHA, требований к профессиям или фиксированного числа типов. Счётчики и проверка точного редакторского delta принадлежат тестам и подготовке поставки.

Материалы исследований удалены из текущего дерева после проверки внешних архивов. Исходная история Git сохранена; подготовка не лицензирует исходные материалы заново.
