# 0.17.0: swipe, Undo, Deleted, Neon, language (UI)

This builds on 0.16.0 (#10, #11). Data contracts are unchanged: Room 13, backup JSON16, `restoreDeleted` and Undo
tied to the deletion batch. There is no permanent delete and no automatic purge.

## Swipe

- A left swipe no longer deletes. It only uncovers a red «Удалить» button behind the row, and the record is
  deleted only when that button is tapped. Deleting still goes through `requestDelete`, with the same Undo and
  confirmation for complex records.
- The intent check is unchanged: a mostly vertical or diagonal movement stays with the list. Only one row can be
  open at a time (`SwipeReveal`). Any scroll of the history closes it, and so does a tap on the open row or a swipe
  back.
- Tests: `deleteFromMenuAndSwipe` checks that a swipe alone changes nothing (screenshot `08-swipe-revealed`). The
  Room recovery test taps the uncovered button.

## Deleted

- Records are grouped by the day they were deleted. Each row reads like a history row: icon, activity, date, time
  range, duration, note.
- Each row has a compact «Восстановить». «Восстановить все (N)» asks first and makes one `restoreDeleted` call.
- Pagination stays at 50.

## Neon

- One shared pulse (`LocalNeonPulse`, 3.4 s each way) drives:
  - three widening strokes under the brackets;
  - a wash of the accent behind the hero: clear while recording, faint at rest;
  - a light around the "AI" of the wordmark;
  - the selected tab.
- Every glow uses the chosen accent, so changing the accent visibly changes Neon.
- The pulse holds still when system animations are off.

## Language

- All Kotlin copy moved to resources in 12 languages: 887 strings and 19 plurals. See
  `localization/ui-copy/README.md`.
  - Where the Russian text matched exactly, the reviewed editorial package was reused. The rest was written for
    this PR; no native-speaker review is claimed.
- `L` gives strings anywhere: composables, the VM, notifications, widgets, the technical shell. Its tag is
  snapshot state, so a language change recomposes in place: no activity restart, drafts and Undo stay.
- Sheets and dialogs are separate windows. They get the chosen language through re-provided locals and through
  the Activity's resources, which are updated in place.
- Preset catalog activities are shown from the bundled reviewed packs (`CatalogNames`, `withCatalogLabels` for
  the picker). This applies only while a record still carries the catalog's own wording; personal names stay as
  written. The Dataset is never rewritten.
- Dates follow the language through `getBestDateTimePattern`. The Russian patterns are kept as before.
- `UiScreensTest.languageSweepLeavesNoRussianCopy` walks all 11 languages: timer, picker, history, Overview and
  Settings in each; English also opens the entry editor, every period and every settings page. It fails on any
  Russian text, label or content description other than the person's own values.
- A resource audit over every `values-*` folder finds no Russian base string without a translation and no Cyrillic
  in any translation; the only gaps are `one` plurals in ja/ko/zh, which those languages never use.
- Tests that assert Russian copy on surfaces now pin `ru-rRU`. The app follows the system language when the
  choice is «Системный».

## Catalog 0.9.3.0

- Short activity names in all 11 packs, written from the short Russian names (`localization/catalog-short/`,
  built by `scripts/catalog_short_labels.py`). Average label length is now about the Russian one (en 33→16,
  es 41→19, fr 42→19, de 37→17 characters). The previous long label stays as the first alias.
- 41 activities that do not belong in a time tracker ship archived: the two intimate cards, grim or seconds-long
  ISCO micro-steps (veterinary euthanasia, checking a buyer's age, releasing collateral, refusing alcohol service,
  journal subscriptions and the like), lottery and the two duplicates of «Казино», and plain duplicates of a
  sibling (quilts, handcycles, wheelchair sprints, short and main sleep, personal messages, garden, streaming
  catalog, equestrian sport, combined canoe/gymnastics/microlight entries, «Судейство соревнований»).
- «Генеалогия» moves to self-directed learning; «Градостроительство» to law and public administration.
- Core: `CatalogEditorialRevision.archive`. An installed type is retired only when the catalog ships it archived
  and nothing in the person's data names its ID; a card, plan, goal, report or past record keeps it live.
  Covered by `CatalogEditorialMoveTest`; an install from 0.9.1.3 and from 0.9.2.0 was also run once by hand
  (0 conflicts, the used type stayed live).
- Three stray Cyrillic strings in pack aliases/descriptions (hi, ja, Kazakh script in several) were cleaned.
