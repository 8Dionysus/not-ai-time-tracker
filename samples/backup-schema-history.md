# Synthetic historical backup schemas

`history-v1-initial.json` uses the first exporter's schema at `2664dd9`, before
`Dataset.types` existed. `history-v1.json` represents the later format-1 schema
at `68c5947` with an explicit type table. Both contain invented example data.

`backup-schema-versions.json` is generated by
`python3 scripts/generate_historical_backup_fixtures.py`. Each array element is
one synthetic backup with the fields and defaults emitted by the whole-object
exporter at the corresponding source revision below. The fixtures exercise
non-default settings, identifiers, a stopped session, its segment, a card,
a favorite, and a measurement. They are not original user exports and do not
claim to cover every possible value or feature in these formats.
